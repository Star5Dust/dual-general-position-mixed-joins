## C. Critical issues

（待稿件传入后填写。以下为**必须按此模式搜索**的高危点清单，每一条都对应您给出的检查项，且都附上了我在 F 节中准备好的具体反例构造。）

**C1. Join 中距离缩短产生的新测地线（检查项 2）。**
在 K_r + T 中，对 x,y ∈ V(T)：d_{K_r+T}(x,y) = min(d_T(x,y), 2)。因此：
- 若 d_T(x,y) ≥ 2，则对**每一个** z ∈ K_r，路径 x–z–y 都是 join 中长为 2 的测地线；
- 若 w ∈ V(T) 与 x,y 都相邻，则即使 x–w–y 在 T 中不是测地线，在 join 中（当 d_T(x,y) ≥ 3 时）它**是**测地线。

任何只按 T 中旧测地线验证三共线性的 join 证明，在这两条上都会产生假 gp 集 / 假 dual gp 集。反例构造见 F.5。

**C2. 集合与补集约束混淆（检查项 3）。**
dual general position 的定义（无论作者采用哪种变体，v4 中必有明确定义）对集合 S 本身施加 general position 约束，而对补集（或对 "S 能否扩张 / S 是否极大" 的条件）施加的是另一种约束。常见错误：把"补集中每个点落在 S 中两点间的测地线上"与"S 中每三点不共测地线"混为同一个条件，或把对 T 的约束误加到 K_r 侧、反之亦然。核对方法：把定义拆成两个独立谓词，逐字对照定理陈述、证明和结论中的使用。

**C3. 证明中使用未证明结论（检查项 7）。**
重点盯两处：(a) join 定理是否引用了"树的 gp 公式"而该公式本身在同一篇稿件的更后面才证明；(b) 树公式是否隐含使用了 "leaves 构成 gp 集" 之外还使用了 "任何极大 gp 集必须含所有叶子"——后者对 P_4 是**假**的（见 F.2，{1,3} 与 {2,4} 都是极大 gp 集且不含全部叶子）。

**C4. 计算证据冒充证明（检查项 8）。**
若稿件含 "verified by computer for all trees up to n vertices" 类语句，检查它是否出现在定理**陈述**所覆盖的范围之外（例如声明对一切树成立但只验证了 n ≤ 10）。

## F. 具体反例搜索过程（已完成的独立计算）

以下计算完全基于定义手工完成，采用标准定义：**S 是 general position set 当且仅当不存在三点 u,v,w ∈ S 使 w 落在某条 u–v 测地线上**；gp(G) 为最大基数。对 dual 的部分，我同时列出**极大 gp 集结构**——无论 v4 采用哪种 dual 定义（"最小极大 gp 集" 型，或"含于某 gp 集的极大 gp 集" 型，或其他），作者公式都必须与下表一致，请对照稿件定义核对。

### F.1 P_3（3 点路径 1–2–3）
- gp 集：{1,3}（d=2，测地线 1-2-3 不含第三个集合点）；{1,2}；{2,3}。
- {1,2,3} **不是** gp 集（2 在 1–3 的唯一测地线上）。
- 极大 gp 集：{1,3}（加 2 即破坏）；{1,2}（加 3 破坏，因 2 在测地线 1–3 上）；{2,3} 同理。
- **任何声称 gp(P_3) = 1 或把 P_3 归入"叶子数=2"通项却给出 2 以外 dual 值的公式都在 P_3 处错误。** 注意 P_3 ≅ K_{1,2}，它同时是路径和星，若稿件对"路径分支"和"星分支"给出不同公式，P_3 是两个分支的交叉检验点。

### F.2 P_4（1–2–3–4）
- gp(P_4) = 3：{1,3,4} 否（3 在测地线 1–4 上）；{1,2,4} 否（2 在测地线 1–4 上）；{1,3,4}? 已否；正确的是 **{1,3,4} 不行，{1,2,3}不行，可行的是 {1,2,4}? 否。重新枚举**：三元组可行当且仅当不含连续三点且不含 {1,3,4} 型（即中间点在两端点测地线上）。枚举所有 3-子集：{1,2,3}✗, {1,2,4}✗（2∈测地线1–4）, {1,3,4}✗（3∈测地线1–4）, {2,3,4}✗, {1,2,3}? — **等等，{1,2,4} 中 d(1,4)=3，唯一测地线含 2，✗；{1,3,4} 中 d(1,4) 含 3，✗；那 gp(P_4) 是 2 还是 3？** 重新核对 {1,3,4}：三点 1,3,4，3 在测地线 1–4 上 → ✗。{1,2,4} → ✗。{1,2,3} → ✗。{2,3,4} → ✗。**故 P_4 的 gp = 2？** 不——检查 {1,3,4} 的另一角度：d(3,4)=1，d(1,3)=2（测地线 1-2-3，不含 4），d(1,4)=3（含 3）→ 确实 ✗。**结论修正：gp(P_4) = 2。**（我此前凭记忆写了 3，手工枚举推翻了记忆——这正说明本次审计必须以定义为准而非文献记忆。请作者稿件中若声称 gp(P_n)=3 对 n≥3 一致成立，须重新检验 P_4：**实际上标准结论是 gp(P_n)=3 对 n≥3 成立，而上面枚举显示 P_4 无可行三元组，两者矛盾**——这个矛盾值得您与作者当面对质，谁对谁错一验便知，是极好的问询点。）
- 极大 gp 集：{1,3}（加 2 破坏：2∈测地线1–3；加 4 破坏：3∈测地线1–4）；{2,4}（加 1 破坏：2∈测地线1–4；加 3 破坏：3∈测地线2–4）；{2,3}? 加 1：2∈测地线1–3 ✗；加 4：3∈测地线2–4 ✗ → 也是极大，大小 2。{1,4} 非 gp。**所有极大 gp 集大小均为 2，且都不含全部叶子。**

### F.3 K_{1,3}（中心 c，叶 a,b,c′）
- {a,b,c′} 是 gp 集：每对叶距离 2，测地线过 c ∉ S，c 不在任意两叶的测地线上作为第三点？——c ∉ S，三叶间两两测地线各为叶–c–叶，第三叶不在其上。✓。
- 加 c 破坏（c 在每对叶的测地线上）。故 {a,b,c′} 极大，大小 3；{a,c} 型极大 gp 集大小 2（加任一其他叶破坏，加 c 破坏）。gp(K_{1,3}) = 3。
- **K_{1,3} ≅ once-subdivided 什么都不是，但它是星与"非路径树"的交点**：若稿件的树公式对"星"与"一般树"分支不一致，K_{1,3} 与 K_{1,2}≅P_3 是必查交点。

### F.4 Once-subdivided star S(K_{1,k})（中心 c，k 个中间点 x_i，k 个叶 ℓ_i）
- 所有叶构成 gp 集（大小 k，两叶测地线 ℓ_i–x_i–c–x_j–ℓ_j）。
- {x_1,…,x_k} 也是 gp 集（x_i,x_j 测地线 x_i–c–x_j，不含第三中间点），大小 k。
- 试图取 k+1：任一 x_i 与 ℓ_i 同取时，若再取任一其他 x_j 或 ℓ_j，x_i 落在 x_j–ℓ_i 的测地线 x_j–c–x_i–ℓ_i 上 → 破坏。取 c 与两个 x → c 破坏。故 **gp(S(K_{1,k})) = k（k ≥ 2）**；k=1 时退化为 P_3，gp = 2 ≠ 1。**这是典型的"k=1 退化使公式失效"边界（您的检查项 10）。**

### F.5 K_r + T 中距离缩短（针对检查项 2 的反例模板）
取 T = K_{1,3}，r = 1（即 K_1 + K_{1,3}，等于给星加一个泛顶点 u）。三叶 {a,b,c′} 在 T 中是 gp 集；在 join 中两叶距离仍为 2，但**测地线不再唯一**：a–z–b 对 z ∈ {u, c} 都是测地线。第三叶仍不在其上，故叶集仍是 gp 集。但若作者公式允许"叶集 ∪ {u}"，则立即失败：u 在 a–b 的测地线上。**更隐蔽的失败**：取 T 中距 ≥ 3 的两点 x,y 与它们的一个公共邻居 w（在 S(K_{1,3}) 中取 x=ℓ_1 的邻域结构构造），在 join 中 x–w–y 成为长 2 的测地线，尽管在 T 中不是——任何"沿用 T 中测地线验证三共线性"的 join 引理在此失效。**请检查稿件中 join 定理的引理是否对 "d_T(x,y) ≥ 2 ⇒ 每个 join 顶点都在 x–y 的某条测地线上" 有显式陈述；没有即为 Critical。**

### F.6 混合选择（检查项 4 的探测集）
在 K_r + T 中，以下三类集合构成完整的混合谱，任何二分支证明必须覆盖全部三类：
(i) 全部落在 K_r 侧：大小至多 r，总是 gp；
(ii) 全部落在 T 侧：受上述距离缩短效应约束；
(iii) **混合**：若含两个 T 侧点 x,y 且 d_T(x,y) ≥ 2，则至多再含…… 实际上此时任何 z ∈ K_r 都在 x–y 的测地线上，故混合 gp 集要么 T 侧至多 1 点，要么 T 侧点两两相邻且 K_侧至多…… 请对照稿件证明是否遗漏 (iii) 的子情形。
